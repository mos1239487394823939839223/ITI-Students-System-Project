# Student Management System

## Overview
The Student Management System is a C# application designed to facilitate the management of student records in an educational environment. It provides a user-friendly interface for performing essential operations related to student information.

## Features
- **Add New Student**: Input and store new student details including name, ID, and grades.
- **Remove Student**: Efficiently delete student records when necessary.
- **Update Grades**: Modify existing grades to reflect current performance.
- **Calculate Grades**: Automatically compute individual and average grades for students.
- **File Management**: Write student information to files for persistent storage and read data from files for easy retrieval.

## Technologies Used
- **Programming Language**: C#
